# Promo video: After Effects project (Module 3)

`build_promo_ae.jsx` builds the 44-second promo as a **native, editable After Effects project** and saves it as `Fawwad_Promo.aep` in this folder. Every title is a real text layer, every move is a keyframe, and the CRT and Game Boy looks are AE effects.

## Build the .aep (once, about 1 minute)

1. **Install the fonts** in `tools/promo/`: `PressStart2P.ttf`, `PlexMono-Medium.ttf`, `PlexMono-Bold.ttf` (right-click > *Install for all users*). Then restart After Effects.
2. In After Effects: **File > Scripts > Run Script File…** and pick `tools/promo/ae/build_promo_ae.jsx`.
   - If AE asks about script permissions: *Edit > Preferences > Scripting & Expressions > Allow Scripts to Write Files and Access Network* (needed to save the project).
3. When it finishes, a message lists any notes (for example a missing font). The project is saved as `tools/promo/ae/Fawwad_Promo.aep`, `PROMO_MAIN` is open, and it is queued in the Render Queue as `public/video/promo_from_ae.mp4`.
4. Render: **Composition > Add to Adobe Media Encoder Queue** (H.264, "Match Source - High bitrate"), or press **Render** in the Render Queue.

Keep the project folder structure as-is: the script finds the footage in `public/` relative to its own location.

## What's inside

| Panel | Contents |
|---|---|
| `01 Main / PROMO_MAIN` | 44 s @ 30 fps, 1920x1080. The 9 scene comps on the timeline, soundtrack with keyframed ducking, glitch adjustment layers at every cut, CRT scanlines (Venetian Blinds adjustment layer) and a vignette |
| `02 Scenes` | `S01_ColdOpen` (Tritone + Posterize Game Boy recolour), `S02_Boot`, `S03_Title` (null-parented portrait card, typewriter text animators, popping skill chips), `S04-S06` game stages (Ken Burns keyframes, lower thirds on a null rig, stage card wipe, progress bar), `S07_Bonus_3DModels` (retro windows), `S08_CharacterSheet`, `S09_Outro` (expression-driven blinking cursor, fade to black) |
| `03 Precomps (crops)` | Blender screen recordings cropped to the 3D viewport (no UI or taskbar) |
| `04 Footage`, `05 Audio`, `06 Images` | Gameplay and turntable videos, the original chiptune `soundtrack.wav`, the portrait |

Gameplay sound comes from the footage layers (+3.5 dB), and the music ducks under it during the stages. The music is original (generated by `tools/promo/make_music.py`), so there are no licensing issues.

## Notes

- The same edit also exists as a code-rendered MP4 (`tools/promo/make_promo.py`), which is what the website currently plays (`public/video/promo.mp4`). After rendering from After Effects you can replace it with your AE render.
- Text positions assume the three fonts above. With other fonts the layout still builds but spacing will differ.
